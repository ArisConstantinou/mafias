VOLT / ROAST — TEST REPORT
Build 1.0.0 · 28 September 2026

Gameplay verification ran in Chromium with the real game JavaScript and WebGL
renderer. Automated fixed-step simulation isolated damage rules and exercised
complete AI matches; this is not a substitute for device play-testing.

PASSED
- Four selectable photo-head riders and four circular item buttons.
- All 24 embedded voice clips decoded successfully.
- Countdown, automatic movement, steering and boost input.
- Contact damage on both scooters, retaliatory projectiles and collision cooldown.
- Heat thresholds: 1, 1, 2, 2, 3, 3, 4 for the first seven hit events.
- Each item actually spawned behind its owner and consumed exactly one stock.
- Banana / pins / oil / toolbox damage: exactly 8 / 16 / 5 / 23.
- Banana skid, oil slide, puncture duration, item cooldown and repeat-hit guards.
- Repair and energy caps; purple supplies restored two item units.
- Pause froze the simulation and resume restored it.
- Both race-finish and last-scooter win conditions produced results.
- Full AI matches completed; AI rivals threw hazards and were eliminated.
- Simultaneous two-finger joystick events produced independent input values.
- Actual circular-image button events threw the selected item.
- Non-overlapping visible dialogue clouds in the checked portrait layout.
- Desktop 1280 x 800, portrait 430 x 932 and landscape 844 x 390 were rendered.
- Offline-browser loading succeeded with all 24 voices still available.
- No JavaScript page errors were reported in the final regression / offline runs.

RENDERING MEASUREMENTS — SOFTWARE TEST HOST ONLY
1280 x 800: approximately 7.4 FPS; render scale 0.70; 143,890 triangles in the sampled frame.
430 x 932: approximately 18.9 FPS; render scale 0.70; 108,370 triangles in the sampled frame.
Renderer: ANGLE / Mesa llvmpipe (software rendering, not a physical GPU).
These low software-renderer frame rates are NOT measurements or forecasts for
an iPhone or a gaming PC. In-game Settings includes a live FPS counter and
resolution controls so actual device performance can be measured.

NOT VERIFIED
- Physical iPhone / Android hardware frame rate, Safari audio behavior or PWA
  installation and cache lifecycle.
- Public hosting / deployment: no external site was created.
- Online multiplayer: it is not implemented in this single-player build.
- Human-naturalness of the synthetic speech or native-speaker translation review.

Screenshots use the real renderer. Action screenshots use a controlled gameplay
state to inspect the heads, hazards, health bars, and subtitle placement.
See tests/regression.json and tests/performance.json for recorded details.
